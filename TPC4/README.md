Resumo:

Neste trabalho fiz um programa, [Aplicação](app.py), que permite criar e ler listas de números, calcular a soma, a média, o maior e o menor elemento, verificar se a lista está ordenada por ordem crescente ou decrescente e procurar um elemento.Tem um menu interativo que permite escolher as operações pretendidas e repetir as opções até selecionar a saída, apresentando no final a lista guardada.

*Nota: Esta é uma versão atualizada do trabalho. Após o feedback do professor, refiz a estrutura do código para corrigir o erro de organização dele, tal como o professor explicou na aula.*
